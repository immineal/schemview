Sharper textures, a cleaner info panel, and fixes.

- Texture pixels keep their hard colours when you zoom in, but their edges are now anti-aliased over one screen pixel, so diagonal pixel lines no longer look jagged. Zoomed out, nothing changes. `SCHEMVIEW_NO_SMOOTH=1` turns it off.
- Fixed light seams along the edges of torches and other small model parts.
- The file info is now a table (format, size, blocks, triangles, name, author, load times) instead of long lines, on the desktop and on Android. `--stats` prints the same table.
- On the desktop, Info and Help are now buttons in the bottom left corner, like on Android. The boxed first letter is the hotkey (`I`, `H`). The help is a table too.
- Old MCEdit `.schematic` files: rails keep their shape, quartz/purpur pillars, hay and bone blocks keep their axis, and anvils, jack o'lanterns, carved pumpkins and end portal frames keep their facing. Chiseled quartz is no longer plain quartz.
- Opening a `file://` path with an unusual character after a `%` no longer crashes.
- Very large compressed files (over 3 GB unpacked, 1 GB on Android) are rejected with a message instead of running out of memory.
- Textures downloaded or imported while a file is loading are now used for that file.
- If OpenGL can't start, the error stays on screen instead of an empty window.

Downloads:

- `linux-x86_64`: unpack and run `./install.sh`. This is the build I use and test.
- `android-arm64.apk`: Android 8.0+, 64-bit ARM. Tested on a Pixel 9a.
- `windows-x86_64`, `macos-arm64`, `macos-x86_64`: built by GitHub Actions, untested.

`SHA256SUMS` has the checksums.
