First public release.

schemview opens Minecraft schematics (`.litematic`, `.schematic`, `.schem`, structure `.nbt`) in a 3D window with the real block textures, read from your own Minecraft install. Orbit, zoom, and use the layer bar on the right to look inside a build one layer at a time.

Downloads:

- `linux-x86_64`: unpack and run `./install.sh` to install it and make it the default app for schematic files. This is the build I use and test.
- `windows-x86_64`, `macos-arm64`, `macos-x86_64`: built by GitHub Actions, untested. On macOS run `xattr -d com.apple.quarantine schemview` once, since the binary isn't signed.

`SHA256SUMS` has the checksums. See the README for controls and limits.
