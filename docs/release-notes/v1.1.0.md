schemview now runs on Android.

- `android-arm64.apk`: the viewer for phones and tablets (Android 8.0+, 64-bit ARM). Touch controls: one finger orbits, two fingers zoom and pan, double-tap resets, and the layer bar works with your thumb. Files open from the app, or with "Open with" / "Share" from file managers and chat apps. The app offers to download the block textures from Mojang's servers, or you can pick a Minecraft `.jar` yourself. Tested on a Pixel 9a.
- The desktop builds have no new features. The code is now a library shared by both apps, and the shaders use high precision everywhere.

`SHA256SUMS` has the checksums. See the README for controls and limits.
